More details
What does ANDA install?

It installs dependencies, creates laptop shortcuts, starts the full local stack, and serves the HUD plus this installer page on port 8080.

Which shortcut should I use?

Use the desktop shortcut named ANDA to start the complete stack. Press Ctrl + Windows key after the daemon is running to toggle the HUD.

Where is the app?

The installer page is at /install.html. The operational HUD is at /index.html.
