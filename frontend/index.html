CONFIGURATION & INFORMATICS

Settings & System Calibration

Customizing hotkeys, audio devices, and security rules.

⌨️ Hardware Keyboard Shortcut Setup +

The default shortcut is Left Ctrl + Windows Key. The daemon captures this using raw Win32 asynchronous keystroke state (VK_LCONTROL = 0xA2, VK_LWIN = 0x5B) polled every 20ms with debouncing.

To dismiss the floating pill at any time, simply press Escape or click anywhere outside the window.

🎙️ Audio & Microphone Calibration +

ANDA uses standard 16kHz mono audio streams. When you click the microphone orb on the floating HUD, it activates the default Windows recording device.

Speech is transcribed automatically via Google Speech / Whisper with local fallback. Ensure Windows Microphone privacy settings have permitted desktop apps.

🛡️ Elevated Daemon & Human-In-The-Loop Safety +

To prevent accidental destruction of operating system data, tasks such as USB flashing, drive formatting, or kernel updates cannot be executed silently by the AI.

The Elevated Daemon drafts a cryptographically hashed capability token and pauses execution until a physical human confirms the prompt.
