# Machine Learning Validation & Hallucination Mitigation Directive

## 1. Objective
Establish continuous verification and supervised quality gates for multimodal data extraction, RAG reasoning, and IPC capability token generation to prevent LLM hallucinations from propagating into the operating system or persistent records.

## 2. Mandatory Verification Gates

### Gate 1: Supervised "Golden Dataset" Verification
- **SOP Requirement:** Maintain a static dataset of 500+ verified test cases containing specific document chunks, receipts, and expected exact outputs.
- **Accuracy Gates:**
  - Data Extraction Exact Match: `>= 95.0%`
  - IPC Token Generation Exact Match: `>= 98.0%`
- **Rejection Rule:** Any regression below these thresholds halts deployment builds immediately.

### Gate 2: Strict RAG Grounding & Citation
- **SOP Requirement:** Every extracted entity, item, and numeric figure must carry citation metadata linking to retrieved vector chunks.
- **Hallucination Detection:** Cross-reference strings and numeric amounts against source chunk text.
- **Action:** Any entity or number not present in the source text is flagged as a hallucination and discarded prior to Excel synthesis.

### Gate 3: Constrained Decoding for IPC Actions
- **SOP Requirement:** Grammar-constrained decoding ensures outputs strictly adhere to the Capability Token schema.
- **Rejection Rule:** Any extraneous keys (e.g. `cmd`, `shell`, `exec`), unapproved actions, or malformed parameters are rejected before dispatch to the Elevated Daemon.

### Gate 4: Visual-Semantic Consistency Loop
- **SOP Requirement:** Click coordinates generated by agents undergo secondary visual inspection.
- **Consistency Check:** The bounding region at `(x, y)` is cropped and checked for contrast and semantic features.
- **Action:** If the crop shows uniform whitespace or element mismatch, execution halts and triggers the Ambiguity Fallback UI.

### Gate 5: Token Confidence Thresholding
- **SOP Requirement:** Evaluate log probabilities and average confidence scores across tool-call parameters.
- **Safety Gate:** If average confidence falls below `0.90`, execution automatically triggers Human-In-The-Loop (HITL) confirmation regardless of privilege level.

## 3. Execution & Automated Testing
- Implementation: `backend/worker/ml_validator.py`
- Test Suite: `tests/test_ml_validation.py`
- Verification Command: `python -m pytest tests/test_ml_validation.py -v`
